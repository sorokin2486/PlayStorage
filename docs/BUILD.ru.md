# Как собрать установщик PlayStorage (один раз)

Сборку делает сам GitHub. Ставить Rust, Node или Git на свой компьютер **не нужно**. Результат — один файл `PlayStorage_1.0.0_x64-setup.exe`, который можно свободно отправлять другим людям.

## Шаг 1. Репозиторий
1. Войдите на [github.com](https://github.com) под своим аккаунтом (sorokin).
2. Нажмите **+** (справа вверху) → **New repository**.
3. Имя: `PlayStorage`. Выберите **Public** (для публичных репозиториев сборка бесплатна). Нажмите **Create repository**.

## Шаг 2. Загрузка файлов
1. Распакуйте архив `PlayStorage.zip`.
2. На странице нового репозитория нажмите ссылку **uploading an existing file**.
3. Откройте распакованную папку и **перетащите всё её содержимое** (папки `src`, `src-tauri`, `docs`, `.github` и файлы `README.md`, `README.ru.md`, `LICENSE`, `.gitignore`) в окно браузера. Папки переносятся целиком.
4. Дождитесь окончания загрузки, внизу нажмите **Commit changes**.

Если файлов больше 100, загрузите в два захода (сначала `src-tauri` и файлы в корне, затем `src` и остальное).

> **Важно:** проверьте, что в репозитории есть путь `.github/workflows/build.yml`. Если папка `.github` не загрузилась (скрытые папки иногда пропускаются), нажмите **Add file → Create new file**, в поле имени введите `.github/workflows/build.yml` и вставьте содержимое файла из архива, затем **Commit changes**.

## Шаг 3. Запуск сборки
1. Откройте вкладку **Actions**. Если GitHub просит, нажмите **I understand my workflows, go ahead and enable them**.
2. Слева выберите **Build PlayStorage**.
3. Справа нажмите **Run workflow** → зелёная кнопка **Run workflow**.
4. Подождите 10-15 минут (первая сборка самая долгая). Жёлтый кружок означает «идёт», зелёная галочка — «готово».

## Шаг 4. Скачивание установщика
1. На главной странице репозитория справа найдите блок **Releases** → **PlayStorage 1.0.0**.
2. В разделе **Assets** скачайте файл `PlayStorage_1.0.0_x64-setup.exe`.
3. Отправьте файл пользователю (Telegram, флешка, облако). Больше собирать ничего не нужно.

Этот файл лежит в Releases постоянно: его можно скачать снова в любой момент.

## Если сборка упала (красный крестик)
Это нормально для первого раза. Откройте упавший запуск → нажмите на шаг с красным крестиком → скопируйте последние ~50 строк лога и отправьте разработчику (мне в чат). Ошибки обычно исправляются за одну итерацию.

## Новая версия
1. Измените номер `version` в `src-tauri/tauri.conf.json` (и в `src-tauri/Cargo.toml`), например на `1.0.1`.
2. Загрузите изменённые файлы в репозиторий (Add file → Upload files, с заменой).
3. Снова запустите **Run workflow**. Появится новый релиз.

Пользователю достаточно запустить новый установщик поверх старого: профили и настройки в `%APPDATA%\PlayStorage` сохранятся.

## Установка у пользователя
1. Запустить `*-setup.exe`.
2. Синее окно SmartScreen: **Подробнее → Всё равно выполнить**.
3. Выбрать язык, нажать «Далее» (права администратора не нужны).
4. Запустить PlayStorage ярлыком; пройти короткий мастер первого запуска.
