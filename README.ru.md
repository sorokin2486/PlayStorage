# PlayStorage by sorokin

Полноэкранный лаунчер игр для Windows 11 в стиле игровой консоли: плитки игр, динамический фон, библиотека, профили, управление геймпадом (DualSense / Xbox) и клавиатурой. Русский и английский языки.

**Автор: Sorokin Ivan** (GitHub: [sorokin](https://github.com/sorokin)) · Лицензия MIT · Версия 1.0.0

> PlayStorage — независимый проект. Он не связан с Sony Interactive Entertainment и не использует её ресурсы (логотипы, шрифты, звуки, иконки). «PlayStation» — товарный знак Sony Interactive Entertainment.

## Для пользователя

### Установка
1. Запустите файл `PlayStorage_x.y.z_x64-setup.exe`.
2. Если Windows показала синее окно «Windows защитила ваш компьютер»: нажмите **«Подробнее»**, затем **«Всё равно выполнить»**. (Установщик не подписан платным сертификатом — это нормально.)
3. Выберите язык установщика, нажимайте «Далее». Права администратора не нужны.
4. Откройте PlayStorage ярлыком на рабочем столе или из меню «Пуск».

При первом запуске мастер предложит выбрать язык, ввести имя и найти игры. Больше ничего настраивать не нужно.

### Управление
| Действие | Геймпад | Клавиатура |
|---|---|---|
| Перемещение | Крестовина / левый стик | Стрелки |
| Выбрать | ✕ (Xbox: A) | Enter / Пробел |
| Назад | ○ (Xbox: B) | Esc / Backspace |
| Параметры игры («…») | Options / Menu | I или F2 |
| Центр управления | Кнопка PS / Xbox / Create | Tab или Home |
| Сменить вкладку | L1 / R1 | Q / E или PgUp / PgDn |
| Поиск | △ (Xbox: Y) | / или Ctrl+F |
| Полный экран | — | F11 |

### Где что находится
- **Главный экран:** вкладки «Игры» и «Мультимедиа», лента плиток, кнопка «Играть». Плитка «+» добавляет игры, последняя плитка открывает библиотеку.
- **Библиотека игр:** вкладки «Все / Недавние / Избранное», сортировка и фильтры, поиск.
- **Меню «…» игры:** избранное, переименовать, сменить обложку и .exe, открыть папку, скрыть, удалить из библиотеки (файлы игры не удаляются).
- **Центр управления:** главный экран, библиотека, громкость, профиль, настройки, питание компьютера (сон, перезагрузка, выключение, выход).
- **Настройки** (шестерёнка справа вверху): руководство, специальные возможности, профиль, система (язык, автозапуск, резервная копия), память, звук, экран, аксессуары, игры и библиотека, уведомления.

Полное руководство есть и внутри программы: **Настройки → Руководство пользователя и информация**.

### Как добавить игры
Плитка **«+»** → выберите один из способов: найти Steam/Epic, просканировать папки, выбрать папку с играми (например, `D:\Games`) или указать `.exe` вручную. PlayStorage пропускает деинсталляторы и служебные файлы, а обложки подгружает из публичных данных Steam. Если обложки нет, рисует свою; свою картинку можно выбрать в меню «…».

### Профили и данные
Все данные лежат в `%APPDATA%\PlayStorage` (нажмите `Win+R` и вставьте этот путь):

| Путь | Что внутри |
|---|---|
| `global.json` | Библиотека игр, добавленные папки, сайты вкладки «Мультимедиа» |
| `profiles\<id>.json` | Профиль: настройки, язык, избранное, скрытые игры, время в играх |
| `covers\` | Загруженные обложки |
| `session.json` | Временный файл итогов игровой сессии |

Эта папка **не удаляется** при деинсталляции, поэтому после переустановки профили и настройки на месте. Резервная копия в один файл: **Настройки → Система → Резервная копия**.

### Как работает запуск игры
При запуске игры окно лаунчера закрывается, чтобы не занимать память. Маленький фоновый процесс следит за игрой (по процессам из её папки), считает время и после выхода снова открывает лаунчер. Отключить: **Настройки → Система → Запуск и поведение**.

### Решение проблем
См. раздел «Если что-то не работает» в руководстве внутри программы. Если лаунчер показывает красный экран с ошибкой, сделайте фото экрана и передайте автору.

## Для разработчика

Стек: **Tauri 2** (Rust) + HTML/CSS/JS без сборщика (`src/`). Node.js для разработки не нужен.

```
src/                  фронтенд (index.html, css/, js/, fonts/, guide/)
  js/main.js          точка входа
  js/screens/         home, library, settings, addflow, filebrowser, wizard, profiles, controlcenter
  js/i18n/ru.js en.js словари (ключи должны совпадать)
src-tauri/            Rust-бэкенд (main.rs), tauri.conf.json, иконки
.github/workflows/    сборка установщика на GitHub
docs/BUILD.ru.md      пошаговая инструкция по сборке
```

Запуск для разработки (нужен Rust и `cargo install tauri-cli --version "^2"`): `cd src-tauri && cargo tauri dev`.
Фронтенд можно открыть и в обычном браузере (`src/index.html`): бэкенд тогда подменяется заглушкой.

Сборка установщика: см. [docs/BUILD.ru.md](docs/BUILD.ru.md).
